Using this in Figma

Figma can't run CSS animation, so bring the mark in as a clean vector, then fake the motion with Smart Animate for previews — and hand this page's code to whoever builds the real thing.

1

Import the vector

Open richfield-mark.svg, select all, copy — then paste straight into a Figma frame. It arrives as three named, editable layers: Shield, Flame and Torch-Stem.

2

Build two frames

Duplicate the frame once. In frame 2, select the ring (or the whole mark, for a simple spin) and rotate it — 120–180° reads well for a loop.

3

Wire Smart Animate

Prototype frame 1 → frame 2 with Smart Animate, linear easing, ~0.5s, trigger "After Delay 0s" — then frame 2 → frame 1 the same way for a seamless preview loop.
